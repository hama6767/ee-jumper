# PPOによる周期モーションの微調整

2026-10-11、CPUで1,024試行を実行しました。最終デモには改善を確認した **+Xと+Z** のPPOモーションを採用し、残る4方向は元の角度軌道を保持しています。

## 学習しているもの

今回のPPOは、既存のCEM泳法に対する周期軌道の係数調整です。
観測は6方向を表すone-hotベクトル、行動は18個の係数補正です。
左右対称性（Y方向は鏡映＋時間反転）から36係数を作り、18関節の角度軌道へ変換します。
毎時刻の姿勢や速度から関節指令を出すE2E方策ではありません。

1回の行動で4周期をシミュレーションし、正味の軸方向変位から横流れ・姿勢変化・小さな仕事量ペナルティを引いた値を評価します。
報酬は `100 × (候補のscore − 元の泳法のscore)`。1試行で終了するため割引率は0です。
scoreの式は[周期制御の説明](cycle_control.md#軌道と評価)にあります。

- 既存泳法: [`strokes-xyz-cem.json`](../examples/strokes-xyz-cem.json)
- 周期1秒、物理2 ms、制御20 ms、並列4環境、seed 73。
- PPO: Stable-Baselines3 2.9.0、PyTorch 2.14.1+cpu、2層×64、学習率0.002、clip 0.2。
- 各環境16試行で更新、batch 64、10 epochs、target KL 0.04。初期の平均補正はゼロ。
- 補正範囲は各係数±0.3、補正後の係数は[-1, 1]。256試行ごとに保存。
- 学習ループの実測293秒。起動・最終評価の時間は含みません。

遊泳関節J0〜J2の18関節は、元の下限を10°下げ、上限を10°上げます。
振幅スケールの上限は1.6→1.8 rad。ホーム姿勢からの各関節の余裕も考慮してスケールを決めます。
補正ゼロでは、範囲が変わっても元の角度軌道になるよう係数を換算します。
手首・指4関節、質量・慣性、最大2 N·m、中性浮力・浮心+10 mmは維持します。
実機の可動域の確認を意味する変更ではありません。

## 比較と採用基準

学習に使用した4秒とは別に、水平・静止から6秒泳いで比較します。
候補は可動域と振幅だけを広げたもの、および256 / 512 / 768 / 1,024試行の決定的方策出力です。
元の泳法より軸方向変位が5%以上増え、scoreが改善することを要求します。
また、横流れは `max(4 cm, 元の1.3倍)` 以下、最大姿勢角は `max(0.35 rad, 元の1.25倍)` 以下、
トルク2 N·m以下、貫通0.5 mm以下などの既存の物理条件も確認します。

選んだ候補だけを、未使用の **初期roll ±3°・12秒遊泳・物理0.5 ms／制御5 ms** で再検証します。
各条件で元の泳法を上回る変位・scoreと同じ横流れ・姿勢条件を満たせなければ元へ戻します。
この段階で次点の候補へ選び直すことはしていません。

| 方向 | 元の6秒変位 cm | 範囲・振幅拡大のみ cm | PPO 1,024試行 cm | 採用 |
|---|---:|---:|---:|---|
| +X | 44.97 | 48.50 | 50.05 | PPO（+11.3%） |
| −X | 42.44 | 44.01 | 43.99 | 元の泳法 |
| +Y | 30.34 | 30.71 | 35.13 | 元の泳法 |
| −Y | 42.53 | 44.91 | 44.67 | 元の泳法 |
| +Z | 16.77 | 17.99 | 17.66 | PPO（+5.3%） |
| −Z | 12.38 | 12.53 | 9.50 | 元の泳法 |

+Yは12秒で横流れ・姿勢変化が増え、−Yは姿勢の条件を超えました。
−Xと−Zは6秒比較の5%改善基準を満たしませんでした。
+Zは拡大だけの方が軸方向には少し速いものの、PPOでは横流れが3.73→1.60 cmに減り、scoreが高くなっています。
+Xの元版からの11.3%増は可動域・振幅の変更も含み、PPO単独による増加率ではありません。

採用した6泳法は[`strokes-xyz.json`](../examples/strokes-xyz.json)に格納し、自由遊泳と固定推力計の値を再計測しています。
元の泳法を残した方向も係数のスケール換算を行い、新しい範囲で元の目標角度を再現します。

再生ではJSONの係数から角度を計算するためPyTorchは不要です。
ROS 2のXYZ指令から1周期ずつ泳法を選ぶコントローラは従来どおりです。
0.08 m/sを10秒指令した閉ループの移動は+Xが78.5 cm、+Zが29.0 cmでした。
6秒間の連続遊泳の改善率が、そのまま速度制御の改善率になるわけではありません。
微細刻みでの6秒変位の差は全方向で0.16〜0.33%でした。

## 再現と成果物

```bash
python -m pip install -e '.[rl]'
ee-jumper-refine-ppo --library examples/strokes-xyz-cem.json \
  --output runs/ppo-refine --steps 1024 --envs 4 --seed 73
python scripts/evaluate_ppo.py --baseline examples/strokes-xyz-cem.json \
  --directory runs/ppo-refine --output runs/ppo-refine/selected.json \
  --report runs/ppo-refine/comparison.json
ee-jumper-gui --library runs/ppo-refine/selected.json
```

`--steps`は物理ステップ数ではなく、4周期を実行する試行数です。
未評価の`candidate-*.json`は再生用ローダーで拒否します。
